# Something is not working { #troubleshooting }

Find your situation and open the relevant guide section.

## For store owners and employees { #store-owners }

| Situation | What to check |
| --- | --- |
| You have not received CRM access or forgot your password | [Access and sign-in](getting-started/registration.md#signing-in-to-the-crm); contact [Tellem support](https://t.me/tellem_tech_bot) for sign-in details or password recovery |
| A product is missing from the app | Its [category](modules/crm/products-and-categories.md#categories), [stock, and availability in the chain](modules/crm/inventory.md#check-chain-availability) |
| The customer sees **Ordering is unavailable** | [The store's fulfillment methods](modules/crm/stores-and-delivery.md), then [the checklist's test order](modules/crm/getting-started.md#test-order) |
| Money arrived, but the order status did not update | [Online payment and accepting an order](modules/crm/orders.md#online-payment), [provider notification settings](modules/crm/payment-providers.md#provider-notifications) |
| An employee does not receive order messages | [Notification recipients, stores, and channels](modules/crm/crm-notifications.md#seller-recipients) |
| A CDEK or Yandex shipment was not created | [The status and message under Delivery information](modules/crm/delivery.md#delivery-information) |
| An iiko error occurred or an order is missing at the till | [Order checks and iiko errors](modules/crm/iiko-errors.md) |
| A mailing failed or was partially sent | [Mailing status and actions after sending](modules/crm/mass-mailings.md#results) |

## For customers { #customers }

| Situation | What to check |
| --- | --- |
| You cannot sign in | [Sign-in methods and requesting a new code](modules/app/account.md#sign-in-and-registration) |
| You cannot place an order or choose fulfillment | [Fulfillment methods and the unavailability message](modules/app/checkout.md#delivery-method) |
| A promo code does not apply | [The message below the promo code field](modules/app/checkout.md#promo-code) |
| Payment is incomplete or the payment deadline expired | [Order confirmation and payment](modules/app/checkout.md#confirmation-and-payment) |
| The app installation option is missing | [Installation on your device](modules/app/account.md#installation) |
| VK messages are not arriving | [Message permission and connection errors](modules/app/customer-notifications.md#if-it-does-not-work) |
| You cannot enable device notifications | [Push notifications and iPhone and iPad restrictions](modules/app/customer-notifications.md#push) |

For payment, cancellation, and refund questions, contact your store through **Profile → Support**, if the store has added its contacts. Include the order number and describe the step where the problem occurred. Before sending a screenshot, hide passwords, confirmation codes, and unnecessary personal data.
