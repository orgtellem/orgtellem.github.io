# Витрина и корзина { #storefront-and-cart }

Выберите товары в каталоге и добавьте их в корзину. Без входа доступны главный экран, каталог, поиск и карточки товаров. Для корзины, избранного и заказов приложение предложит [войти](account.md).

Если магазин показывает предупреждение «Контент 18+», продолжить можно только после подтверждения «Мне есть 18».

<span id="_2"></span>

## Главный экран { #home-screen }

Нажмите название и адрес в шапке, чтобы выбрать магазин или сеть магазинов (зону продаж). От выбора зависят каталог и наличие. Гость, открывший ссылку или QR-код конкретного магазина, попадает в его каталог.

Откройте «Каталог» для выбора товаров, «Избранное» для сохранённых позиций или «Уже заказывали», чтобы найти покупки из предыдущих заказов. Блоки и предупреждения на главной зависят от настроек магазина; предупреждение магазина видно только после входа.

Поиск находится внизу экрана. Кнопка корзины появляется, когда в ней есть товары, и показывает их количество и сумму.

<span id="_3"></span>

## Каталог и поиск { #catalog-and-search }

Выберите категорию или введите запрос в поиске: результаты по товарам и категориям появляются при вводе. Если ничего не найдено, измените запрос или проверьте выбранную зону продаж.

<span id="_4"></span>

## Карточка товара { #product-card }

В карточке проверьте описание, характеристики, цену и наличие. Если у товара есть варианты, например размер или цвет, выберите нужный перед добавлением. Нажатие на фото открывает его на весь экран; на артикул, то есть код товара, копирует код.

- **«Купить»** добавляет товар и открывает корзину, где отмечен только он.
- **«В корзину»** добавляет товар без перехода. У уже добавленного товара эта кнопка открывает корзину; количество можно изменить рядом, в пределах остатка.
- У товара без остатка видна неактивная кнопка **«Нет в наличии»**. При небольшом остатке в карточке показано точное количество.

«Поделиться» открывает системное меню или копирует ссылку. У вошедшего покупателя ссылка открывает товар внутри Telegram, если магазин подключил бота; иначе она ведёт на сайт.

### Размер и добавки к блюду { #dish-options }

Если у блюда есть размеры, выберите нужный вариант товара. При добавлении блюда с добавками выберите их в открывшемся окне. Обязательные группы отмечены «*»; рядом указано допустимое количество. Кнопки «−» и «+» у добавки доступны, если магазин разрешил несколько порций. Без обязательного выбора добавить блюдо нельзя.

Проверьте итоговую цену с добавками перед добавлением. Акции и скидка ко дню рождения уменьшают цену самого блюда; стоимость добавок остаётся прежней.

<span id="_5"></span>

## Избранное { #favorites }

Нажмите сердечко на карточке товара, чтобы сохранить его в «Избранное». «Очистить» удаляет весь список после подтверждения.

<span id="_6"></span>

## Корзина { #cart }

1. Отметьте товары для заказа. При открытии корзины выбраны все позиции; неотмеченные останутся в корзине.
2. Проверьте количество: оно не может превышать остаток. После уменьшения до нуля можно нажать «Вернуть», пока кнопка видна.
3. Проверьте «Итого» по выбранным позициям и нажмите «Оформить заказ на <сумма>». Промокод и бонусы применяются на следующем шаге: [оформление заказа](checkout.md).

!!! warning "Удаление товаров"
    «Удалить» убирает все отмеченные позиции после подтверждения. Отменить такое удаление нельзя.

Если магазин резервирует товары в корзине, резерв и количество в корзине сбрасываются после периода бездействия. Перед оформлением проверьте корзину заново.

У блюда с добавками нажмите **«Изменить»**, чтобы поменять состав. Один товар с разными добавками или их количеством занимает отдельные строки; одинаковые варианты объединяются. Размер и добавки сохраняются в заказе.

## Профиль, заказы, документы и тема { #profile-orders-documents-and-theme }

Адреса, бонусы, язык, тема и установка доступны в [профиле](account.md). Статусы и действия с заказами описаны в разделе [«Оформление и заказы»](checkout.md#orders).

[Правовые документы Tellem](../../legal/index.md) доступны по ссылкам в приложении: в подвале главной, профиля и «О приложении», при входе и оформлении заказа, а также в баннере cookie. Документы открываются на языке интерфейса.

    Настройте [варианты товара по цвету](../crm/product-colors.md), [главный экран и цвета приложения](../crm/main-page.md). Размеры и добавки к блюдам загрузите из [меню iiko](../crm/iiko.md#sizes-and-extras). Предупреждения, резервирование и информационные разделы профиля находятся в [основных настройках](../crm/general-settings.md). Ссылку и QR-код конкретной точки получите в [карточке магазина](../crm/stores-and-delivery.md).
