# Клиентское приложение { #customer-app }

Откройте ссылку своего магазина в браузере. Если магазин подключил Telegram-бота, приложение можно открыть и из него. Каталог доступен без входа; для оформления заказа [войдите в аккаунт](account.md#sign-in-and-registration).

<div class="grid cards" markdown="1">

- :material-cart-outline: **Выбрать товары**

    Найти товар, выбрать вариант и проверить корзину.

    [Витрина и корзина](ui-and-pages.md)

- :material-clipboard-check-outline: **Оформить заказ**

    Выбрать получение и оплату, применить промокод, проверить статус заказа.

    [Оформление и заказы](checkout.md)

- :material-account-circle-outline: **Настроить аккаунт**

    Войти, изменить личные данные, подключить бонусы или установить приложение.

    [Аккаунт и установка](account.md)

- :material-bell-outline: **Получать уведомления**

    Подключить Telegram, VK, e-mail или уведомления на устройстве.

    [Уведомления покупателю](customer-notifications.md)

</div>

Если не удаётся оплатить, применить промокод или включить уведомления, откройте [помощь покупателю](../../troubleshooting.md#customers). По вопросам покупки обращайтесь в свой магазин через **Профиль → Поддержка**, если магазин указал контакты.

!!! info "Для владельца"
    Настройка магазина и работа с заказами описаны в [CRM](../crm/index.md). Перед открытием магазина пройдите [чек-лист запуска](../crm/getting-started.md).
