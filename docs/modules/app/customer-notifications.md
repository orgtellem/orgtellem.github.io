# Уведомления покупателю { #customer-notifications }

Подключите сообщения о заказах и бонусах в **Профиль → Уведомления**. Статус заказа можно проверить и в [«Мои заказы»](checkout.md).

## Куда присылать { #channels }

В блоке «Куда присылать» видны Telegram, VK и e-mail, которые предлагает магазин. Сообщения приходят во все включённые и доступные каналы. Выключенный канал не заменяется другим. Push на устройстве [включаются отдельно](#push).

У подключённого канала есть переключатель. Если магазин предлагает единственный канал и он уже включён, переключателя нет. Последний включённый канал выключить нельзя: сначала подключите или включите другой. Если ни один канал не включён, следуйте подсказке «Подключите канал…».

Чтобы подключить канал, нажмите действие в его строке:

- **Telegram:** «Подключить» или «Открыть бота», если он не запущен. [Запустите бота магазина](#telegram).
- **VK:** «Подключить» для привязки аккаунта или «Разрешить» для разрешения сообщений. [Подключите сообщения сообщества](#vk).
- **Почта:** «Добавить», если адреса нет, или «Подтвердить». Откроются «Личные данные»; код придёт на указанный адрес. До подтверждения переключателя нет.

Вход по коду из письма тоже подтверждает e-mail. Для писем о заказах магазин должен подключить отправку почты, а вы должны включить почту в «Куда присылать». Письма входа и письма, отправленные магазином вручную, этот переключатель не отключает.

## VK { #vk }

<span id="vk_1"></span>

### Войдите или привяжите VK { #sign-in-or-link-vk }

На экране «Вход или регистрация» выберите **VK ID**. Если аккаунт магазина уже есть, сначала войдите привычным способом, затем нажмите «Привязать» рядом с VK в профиле или «Подключить» в **Профиль → Уведомления**. Так сообщения будут связаны с вашими заказами. После подключения из «Уведомлений» вы вернётесь на тот же экран.

![Вход или регистрация: кнопка VK ID над формой e-mail.](../../media/vk-setup/customer-login.png){ width="440" }

<span id="_2"></span>

### Разрешите сообщения { #allow-messages }

1. После входа или привязки в окне «Уведомления в VK» разрешите сообщения кнопкой VK. Используйте тот же аккаунт VK, который привязан к магазину.
2. Дождитесь завершения подключения. Если разрешение уже выдано, нажмите «Подключить уведомления».

![Окно «Уведомления в VK»: кнопка «Подключить уведомления», когда разрешение на сообщения уже выдано.](../../media/vk-setup/customer-connect.png){ width="352" }

Разрешение действует для личных сообщений сообщества о заказах и бонусах, а также рассылок, если вы их включили. Оно не добавляет вас в участники сообщества и не подписывает на его записи.

«Позже» закрывает предложение; вход и заказы остаются доступными. Вернуться к подключению можно через «Разрешить» в строке VK на экране «Уведомления», без повторного входа.

<span id="_3"></span>

### Если не получилось { #if-it-does-not-work }

| Сообщение | Что сделать |
|---|---|
| «В виджете открыт другой аккаунт VK» | Переключите VK на аккаунт, привязанный к магазину |
| «Виджет VK недоступен» | Нажмите «Повторить» или «Открыть VK», разрешите сообщения в диалоге сообщества и вернитесь к «Подключить уведомления» |
| «Не удалось подключить уведомления» | Повторите «Подключить уведомления»; заново выдавать разрешение не нужно |

Чтобы остановить сообщения, выключите VK в «Куда присылать» или запретите их в диалоге с сообществом. Вход через VK ID и покупки останутся доступны.

После запрета в VK строка канала обновится при ближайшей попытке отправить сообщение и покажет «Разрешить». Для возобновления нажмите эту кнопку в приложении магазина. Повторная привязка VK или разрешение, выданное только в самом VK, доставку не возобновят.

## Telegram { #telegram }

Нажмите **Telegram** на экране входа, «Привязать» рядом с Telegram в профиле или «Подключить» в **Профиль → Уведомления**. В боте магазина нажмите **Start / «Запустить»** и вернитесь в приложение: статус обновится. Если бот остановлен или заблокирован, сообщения не придут; нажмите «Открыть бота» и запустите его.

В приложении внутри Telegram аккаунт подключается при открытии магазина. Если бот ещё не запущен, выполните подсказку «Нажмите «Запустить» в чате с ботом».

<span id="e-mail"></span>

## E-mail { #email }

Подключите и подтвердите почту в [«Куда присылать»](#channels). Если вы поменяли адрес в «Личных данных», подтвердите новый адрес кодом из письма.

<span id="push-notifications-on-your-device"></span>

## Push на устройстве { #push }

После входа откройте **Профиль → Уведомления**, включите «Push-уведомления» и разрешите их в запросе браузера. Они сообщают о смене статуса заказа на этом устройстве; нажатие открывает заказ. Рассылки и сообщения о бонусах через push не приходят.

Если видна подпись «Запрещены в настройках браузера», разрешите уведомления в браузере или системе. На iPhone и iPad сначала [установите приложение на экран «Домой»](account.md): в обычной вкладке push недоступны. Если карточки push нет, браузер или магазин их не поддерживает.

Выход из аккаунта отключает push на этом устройстве: после нового входа включите их снова. «Выйти со всех устройств» останавливает push на остальных устройствах до следующего входа на них.

## Уведомления о заказе и рассылки { #mailings }

Переключатель «Рассылки» вверху экрана управляет информационными сообщениями магазина: новостями и полезной информацией, а не рекламой. Он не управляет сообщениями о заказах и бонусах, включая напоминания о сгорании бонусов.

Для рассылок нужны включённые «Рассылки» и хотя бы один подключённый канал в «Куда присылать». Для VK также требуется разрешение на сообщения сообщества. Если несколько каналов включены и доступны, рассылка придёт в каждый.

!!! info "Для владельца"
    Подключите [сообщество VK](../crm/vk.md) или [Telegram-бота](../../getting-started/bot-setup.md). Информационные сообщения создаются в [«Рассылках»](../crm/mass-mailings.md). Настройки [«Уведомления» в CRM](../crm/crm-notifications.md) предназначены для сотрудников; покупатель подключает каналы в своём приложении.
