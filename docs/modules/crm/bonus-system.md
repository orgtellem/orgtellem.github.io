# Бонусная система { #loyalty-program }

Покупатели копят бонусы за заказы и оплачивают ими часть стоимости товаров. Один бонус равен одной денежной единице магазина, например 1 ₽ для магазина с ценами в рублях.

Где: **Маркетинг → Бонусы**. Подключение программы покупателем описано в [профиле приложения](../app/account.md).

## Включить и настроить { #enable-and-configure }

Перед включением проверьте действующие правила: проценты накопления, ограничения списания, приветственный подарок и срок действия. Для правил Tellem нажмите «Настроить». Стороннюю бонусную систему согласуйте с командой Tellem.

1. Выберите набор правил или нажмите «Создать новые правила». Действующим может быть только один набор.
2. Добавьте хотя бы одно условие накопления: сумма заказа от 0 и процент от 1 до 99. Задайте максимальную долю списания от 0 до 100 % и решите, разрешать ли одновременное списание и накопление.
3. При необходимости включите приветственные бонусы. Покупатель получает их при подключении программы, а не при регистрации в магазине.
4. Для нового набора нажмите «Сделать действующими», затем «Сохранить правила». Без первого действия набор останется черновиком. Изменения действующих правил также применяются после сохранения.
5. Включите бонусную систему переключателем на основном экране. Этот же переключатель сразу выключает программу.

!!! warning "Удаление правил"
    Удалить можно только неактивный набор. «Удалить правила» удаляет его сразу, без подтверждения.

## Как считаются бонусы { #how-points-are-calculated }

- База расчёта: стоимость товаров с учётом акций, промокода и [комиссии способа оплаты](payment-providers.md). Доставка в неё не входит.
- Для начисления используется наибольший процент среди условий, порог которых не превышает базу. При разрешённом одновременном списании и накоплении порог и процент считаются от базы за вычетом списанных бонусов. Без такого разрешения заказ со списанием ничего не начисляет.
- Сумма начисления округляется вниз и фиксируется при создании заказа; последующие правки правил её не меняют. Покупатель получает бонусы после завершения заказа.
- Списать можно не больше заданной доли базы и доступного баланса. Сначала тратятся бонусы с ближайшим сроком сгорания.
- При отмене или возврате заказа списанные бонусы возвращаются, а начисление за завершённый заказ отменяется. Возвращённые бонусы сохраняют прежний срок; если он прошёл, они действуют ещё 7 дней. Уже сгоревшие бонусы повторно не списываются.

Баланс и операции конкретного покупателя доступны в [карточке клиента](clients.md#bonuses).

Денежная база для количества бонусов округляется вниз до целой единицы валюты; порог процента начисления проверяется по точной сумме. При онлайн-оплате списание ограничивается так, чтобы положительный остаток достигал минимума платёжного сервиса. Полностью покрытый заказ считается оплаченным без перехода на страницу оплаты.

## Бонусы в день рождения { #birthday }

В **Маркетинг → Бонусы → Настроить** откройте действующий набор правил Tellem, включите «Начислять бонусы в день рождения», укажите положительное целое количество и нажмите «Сохранить правила». Бонусная система должна быть включена.

![Настройка подарочных бонусов в действующем наборе правил.](../../media/birthday-rewards/crm-bonus-rule.png)

Одновременно можно включить один подарок: бонусы или [скидку ко дню рождения](promo-codes.md#birthday). Чтобы сменить вариант, сначала выключите прежний в его редакторе. Уже начисленные бонусы сохраняются.

Подарок получает участник программы с датой рождения, сохранённой до начала праздника. Счёт автоматически не создаётся; покупатель может [подключить программу](../app/account.md#birthday) в сам праздник, если указал дату заранее. Покупка для подарка не нужна. Бонусы могут появиться с задержкой; у них такой же срок действия, как у новых начислений. Отмена заказа не отменяет подарок.

### Компенсировать пропущенный подарок { #birthday-compensation }

Пропущенный день рождения автоматически не компенсируется. В **Клиенты → карточка клиента** владелец или администратор может нажать «Компенсировать подарок в день рождения» и подтвердить действие.

Компенсация доступна для сохранённого клиента за последний наступивший день рождения, в том числе в прошлом календарном году. Дата должна быть указана заранее, подарочные бонусы включены, а счёт Tellem уже создан. Повторное подтверждение не выдаёт второй подарок за тот же год.

## Срок действия и напоминания { #expiry }

В правилах Tellem включите «Ограничить срок действия» и задайте положительное целое число дней.

- Каждое новое начисление, включая ручное пополнение, действует это число дней с момента зачисления.
- При первом включении накопленный остаток получает полный срок от сохранения правил.
- Изменение или отключение срока не меняет даты уже начисленных бонусов. Повторное включение задаёт срок только бонусам без даты сгорания.

В блоке «Предупреждать гостей» включите «Напоминать о сгорании» и укажите срок предупреждения: от одного дня до полного срока действия бонусов. Напоминание с суммой и датой сгорания по всемирному времени (UTC) приходит в доступные включённые каналы Telegram, VK и почты; оно может прийти с задержкой.

Это служебное сообщение: отказ от рассылок и настройка уведомлений Telegram «Массовая рассылка» его не выключают. Доступность каналов покупатель проверяет в [профиле](../app/account.md#channels).

Если бонусы потрачены до отправки, напоминание отменяется. На одну дату сгорания каждый доступный канал получает одно напоминание; подключённый позже канал его не получит. Канал, выключенный или недоступный к моменту отправки, тоже не получит сообщение.
