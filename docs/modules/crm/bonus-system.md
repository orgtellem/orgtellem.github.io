# Активация бонусной системы для клиентов

Инструкция описывает активацию и настройку бонусной системы в CRM. Работа ведётся на двух экранах:

- «Бонусная система» — основной экран управления.
- «Редактирование бонусной системы» — детальная настройка правил.

## 1. Экран «Бонусная система»

Экран доступен в разделе меню «Маркетинг», пункт «Бонусы».
Здесь включается и выключается бонусная система, выбирается активный провайдер, просматриваются активные правила и
аналитика по использованию клиентами.

**Основные элементы:**

- Переключатель состояния вверху карточки — включает и выключает бонусную систему.
- Поле «Система учёта бонусов» — выбор активного провайдера. По умолчанию используется внутренняя бонусная система
  Tellem. Если есть потребность подключить интеграцию со сторонней бонусной системой — напишите нам.
- Блоки «Правила накопления», «Правила списания», «Приветственные бонусы» — отображение активных правил.
- Кнопка «Настроить» — открывает детальную настройку.

**Как включить и выбрать провайдера:**

1. Включите переключатель состояния вверху экрана.
2. Убедитесь, что в блоке правил отображаются актуальные параметры.
3. Нажмите кнопку «Настроить», если хотите сконфигурировать собственные правила.

## 2. Экран «Редактирование бонусной системы»

Экран открывается по кнопке «Настроить». Здесь создаются и редактируются наборы правил.

**Структура экрана:**

- Вкладки правил. Есть вкладка «Создать новые правила».
- Поле «Наименование» — название набора правил для вашего удобства (оно же название вкладки).
- Раздел «Правила накопления» — условия начисления.
- Раздел «Правила списания» — параметры использования бонусов.
- Раздел «Приветственные бонусы» — бонусы за вступление покупателя в бонусную программу.
- Кнопки действий: «Сохранить правила», «Сделать действующими», «Удалить правила».

### 2.1 Создание нового набора правил

1. Нажмите вкладку «Создать новые правила».
2. Заполните «Наименование» — это имя набора.
3. В разделе «Правила накопления» добавьте условия:
    - Нажмите «Добавить условие».
    - Заполните:
        - «Сумма заказа от» — минимальная сумма заказа (0 или больше).
        - «Начисление» — процент начисления (от 1 до 99).
    - Можно добавить несколько условий с разными порогами.
4. В разделе «Правила списания» задайте:
    - «Макс. процент для списания в заказе» (от 1 до 99).
    - Переключатель «Разрешено одновременное списание и накопление» — можно ли одновременно тратить и получать бонусы в
      одном заказе.
5. В разделе «Приветственные бонусы»:
    - Включите «Приветственные бонусы активны».
    - Укажите «Приветственные бонусы» — сколько бонусов покупатель получит при вступлении в бонусную программу.
6. Нажмите «Сохранить правила».

### 2.2 Сделать набор правил активным

Наборов правил может быть несколько, переключаться между ними можно в один клик.

1. Откройте вкладку нужного набора.
2. Нажмите «Сделать действующими».

!!! warning
    Активным может быть только один набор правил.

### 2.3 Удаление набора правил

1. Откройте вкладку неактивного набора.
2. Нажмите «Удалить правила».

!!! note
    Активные правила удалить нельзя — сначала сделайте действующим другой набор.

## 3. Как считаются бонусы

1 бонус равен 1 ₽. База расчёта — сумма товаров заказа с учётом комиссии; стоимость доставки в расчёте не участвует.

**Начисление:**

- Из условий «Правил накопления» применяются те, чей порог «Сумма заказа от» не превышает сумму товаров заказа.
  Если под сумму подходят несколько условий, используется наибольший процент «Начисление».
- Бонусы зачисляются на баланс покупателя после перевода заказа в статус «Завершён».

**Списание:**

- За один заказ покупатель списывает не больше «Макс. процент для списания в заказе» от суммы товаров заказа и не
  больше своего текущего баланса.
- Переключатель «Разрешено одновременное списание и накопление»:
    - включён — при списании бонусы начисляются от суммы товаров за вычетом списанных бонусов;
    - выключен — заказ, в котором списаны бонусы, новых бонусов не приносит.

## 4. Проверка после настройки

1. Вернитесь на экран «Бонусная система».
2. Убедитесь, что выбран нужный провайдер и отображаются актуальные правила.
3. Проверьте блок аналитики — данные должны обновиться.

## 5. Бонусы для покупателей клиентского приложения

Покупатель работает с бонусами в профиле приложения.

**Вступление в бонусную программу:**

1. Покупатель открывает профиль и нажимает «Подключить бонусную систему» на карточке бонусов.
2. Приложение запрашивает доступ к номеру телефона — покупатель нажимает «Разрешить».
3. Если номер телефона магазину ещё не известен, покупатель вводит его в окне «Укажите номер телефона».

После вступления создаётся бонусный аккаунт. Если включён переключатель «Приветственные бонусы активны», приветственные
бонусы зачисляются сразу при вступлении; если выключен — аккаунт создаётся с нулевым балансом.

!!! note
    Приветственные бонусы начисляются именно при вступлении в бонусную программу, а не автоматически при регистрации
    покупателя в магазине.

**На экране «Бонусы» покупатель видит:**

- Баланс бонусов.
- Правила накопления — пороги «от N ₽» и проценты начисления.
- Историю бонусных операций.

Правила списания на экране «Бонусы» не показываются. Доступный лимит списания покупатель видит при оформлении заказа:
на чекауте отображается, сколько бонусов можно списать на этот заказ.
