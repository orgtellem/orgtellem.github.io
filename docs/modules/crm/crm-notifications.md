# Настройка уведомлений

Настройка уведомлений выполняется в разделе «Настройки → Уведомления».

В правой части экрана расположены два списка: «Уведомления для продавцов» и «Уведомления для клиентов».
Выберите вид уведомления — слева откроются его описание, параметры и таблица «Получатели уведомления».

---

## Виды уведомлений для продавцов

- **«Низкое количество товара»** — срабатывает, когда в магазине остаётся меньше товара, чем указано в поле
  «Если менее» (по умолчанию — 5 шт.).
- **«Уведомление об отмененном заказе»** — срабатывает, когда покупатель отменяет свой заказ.
- **«Уведомление о новом заказе»** — срабатывает, когда в систему поступает новый заказ.
- **«Уведомление о просроченной оплате»** — срабатывает, когда покупатель не оплатил заказ за отведённое время.
  Время ожидания оплаты задаётся в разделе «Настройки → Оплата» в поле «Время ожидания платежа (в минутах)».
- **«Напоминание о непросмотренных заказах»** — отправляется повторно через заданное количество минут
  (по умолчанию — 20 мин), пока новый заказ не обработан, то есть не переведён в следующий статус.

Рядом с названием каждого уведомления находится переключатель, который включает и выключает его отправку.

---

## Добавление получателя уведомлений

Получатель выбирается из списка клиентов: сотрудник должен быть пользователем Telegram-бота магазина,
то есть присутствовать в разделе «Клиенты».

1. Выберите вид уведомления в списке «Уведомления для продавцов».
2. В таблице «Получатели уведомления» нажмите «Добавить».
3. В открывшемся окне выберите сотрудника из списка клиентов.

Добавленный получатель отображается в таблице с его юзернеймом в Telegram, фамилией и именем.
Настройте его параметры прямо в таблице:

- **«Телеграм»** и **«Эл. почта»** — два независимых переключателя каналов доставки, можно включить оба.
  По умолчанию включён только «Телеграм».
- **«Адрес Эл. Почты»** — адрес, на который придут письма. Заполните его, если включён канал «Эл. почта».
- **«Магазины»** — магазины, по заказам из которых сотрудник будет получать уведомления.
  Уведомления о заказах из других магазинов ему не приходят.

!!! warning "Поле «Магазины» обязательно"
    Получатель без указанного магазина не получит уведомление.

!!! note
    Для уведомления «Низкое количество товара» магазины не выбираются — колонки «Магазины» в его таблице
    получателей нет.

## Уведомления для клиентов

В блоке «Уведомления для клиентов» находится уведомление «Изменение статуса заказа» — покупатель получает его
при смене статуса своего заказа. К системному уведомлению можно добавить собственное сообщение для каждого
статуса заказа:

1. Откройте «Изменение статуса заказа» в списке «Уведомления для клиентов».
2. Создайте запись, укажите «Статус» и «Сообщение».
3. Поле «Итоговое сообщение» показывает, как уведомление будет выглядеть у покупателя.

Для каждого статуса заказа можно создать только одно сообщение — чтобы изменить текст, отредактируйте
существующую запись.

!!! tip
    В тексте сообщения можно использовать системные атрибуты заказа — укажите имя атрибута по маске `%name%`.
