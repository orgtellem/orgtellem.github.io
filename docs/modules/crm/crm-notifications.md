# Уведомления { #notifications }

Настройте сообщения сотрудникам о заказах и остатках и добавьте текст к уведомлениям покупателей.

Откройте **Настройки → Уведомления** и выберите уведомление в списке справа.

<span id="for-sellers"></span>

<span id="_2"></span>

## Для продавцов { #seller-notifications }

| Уведомление | Когда приходит |
|---|---|
| Низкое количество товара | Остаток изменился и стал меньше значения **Если менее**; архивные товары не учитываются |
| Уведомление о новом заказе | Создан заказ **Новый** или **Ожидает оплаты**, ещё до оплаты |
| Уведомление об отмененном заказе | Покупатель или сотрудник отменил заказ |
| Уведомление о просроченной оплате | Неоплаченный заказ отменён или получил **Ошибка оплаты** из-за истечения срока либо отказа в оплате |
| Напоминание о непросмотренных заказах | С заданным интервалом, пока есть заказы **Новый**; интервал в минутах задаётся полем **Если менее** |
| Ошибки iiko | Не удалось передать заказ, обновить его статус или стоп-лист; сообщение содержит [дальнейшие действия](iiko-errors.md) |

Срок ожидания платежа задаётся в [способе оплаты](payment-providers.md).

## Получатели { #seller-recipients }

1. В **Получатели уведомления** нажмите **Добавить** и выберите аккаунт сотрудника из списка клиентов. Подойдёт аккаунт без Telegram.
2. Выберите **Канал**: **Все каналы** использует все доступные; **Автовыбор** — один, сначала Telegram, затем почту. Можно указать конкретный канал. Контакты берутся из карточки клиента.
3. Выберите **Магазины**, по которым сотрудник должен получать сообщения. Без выбранного магазина сообщения не придут. У уведомления о низком остатке этого поля нет.

Настройки сохраняются сразу. Для Telegram нужны привязанный аккаунт и включённая [интеграция с ботом](../../getting-started/bot-setup.md). Для почты нужна настроенная отправка на платформе. Недоступные каналы пропускаются.

!!! warning "Отключение уведомления"
    У уведомлений для продавцов переключатель включения управляет отправкой в Telegram; письма выбранным получателям продолжают приходить.

У **Ошибки iiko** отдельного переключателя нет: уведомление включено, пока сохранено хотя бы одно подключение iiko. Получатели общие с шагом **Уведомления** в мастере подключения. Без получателей сообщение не придёт никому; если заведение ошибки неизвестно, его получат все выбранные сотрудники.

## Для клиентов { #customer-status }

Покупатель получает **Изменение статуса заказа** во всех [доступных и включённых им каналах](../app/customer-notifications.md). Настройка получателей для продавцов на него не влияет.

Чтобы добавить свой текст к системному сообщению:

1. Нажмите **Создать**, выберите **Статус** и введите **Сообщение**.
2. Проверьте **Итоговое сообщение** и сохраните. Для одного статуса допускается одно сообщение; для изменения правьте существующее.

Текст добавляется к сообщениям в Telegram, VK и почте; в push его нет. Отправляется основной текст, без переводов.

Маска `%name%`, где `name` — имя системного атрибута заказа, подставляет его значение. Такие атрибуты могут заполнять [пользовательские интеграции](integrations.md#пользовательские).
