# Catalog { #catalog }

For a new store, first set up [locations, fulfillment, and payments](stores-and-delivery.md). Then add products, set stock, and check them in the customer app.

<div class="grid cards" markdown="1">

- :material-store-outline: **Stores**

    Create a location or chain and enable available fulfillment and payment methods.

    [Set up stores](stores-and-delivery.md)

- :material-shape-outline: **Categories and products**

    Create products manually, add variants, and assign categories.

    [Add products](products-and-categories.md)

- :material-file-upload-outline: **Import**

    Upload categories and products from CSV or YML; add a restaurant menu from iiko.

    [Import a catalog](catalog-import.md) · [Add an iiko menu](iiko.md#import-products)

- :material-palette-outline: **Color variants**

    Group products and let customers choose a color.

    [Group products](product-colors.md)

- :material-warehouse: **Stock and availability**

    Set quantities at each location or remove a product from sale.

    [Change stock](inventory.md)

- :material-view-dashboard-outline: **Design**

    Choose home screen blocks and app colors.

    [Design the app](main-page.md)

</div>

If customers cannot see a product, check its [category](products-and-categories.md#categories) and [availability in the store chain](inventory.md#check-chain-availability). For the full setup sequence, follow the [launch checklist](getting-started.md).
