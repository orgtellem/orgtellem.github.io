# Рассылки { #mailings }

Отправьте сообщение клиентам сразу или в назначенное время. Для выбора получателей доступны все клиенты или [RFM-сегменты](analytics.md#rfm) одной точки.

Где: **Маркетинг → Рассылки**. На телефоне выберите **Действия → Создать**.

<span id="_2"></span>

## Получатели и каналы { #recipients }

Рассылка приходит клиентам с включёнными «Рассылками» во все доступные каналы, которые они не выключили в [профиле](../app/account.md#channels):

- Telegram: интеграция включена, клиент запускал бота и не заблокировал его;
- VK: [сообщество магазина подключено](vk.md), клиент привязал VK ID и разрешил сообщения;
- почта: адрес подтверждён и отправка почты доступна магазину.

В форме каналы не выбираются: «Автовыбор» использует доступные каналы при отправке. Выключенный канал другим не заменяется. Изображение приходит только в Telegram, VK получает текст и ссылки, почта текст. Сообщение только с изображением уйдёт только в Telegram. Push для рассылок не используется.

«Доступная аудитория: N клиентов» считает подписанных клиентов выбранной аудитории, в том числе без доступного канала; это не число доставленных сообщений.

!!! warning "Реклама требует отдельного согласия"
    Переключатель «Рассылки» относится к информационным сообщениям. Он не заменяет отдельное предварительное согласие на рекламу. Продавец получает согласие и отвечает за содержание сообщений; см. [правовые документы](../../legal/index.md).

[Напоминания о сгорании бонусов](bonus-system.md#expiry) настраиваются отдельно и не зависят от отказа от рассылок.

## Создать и отправить { #create-and-send }

1. Нажмите «Создать». Для выбранной аудитории включите «Использовать RFM-сегменты», выберите сегменты и точку. Используется расчёт за всё время; единственная точка выбирается автоматически. Без флажка получателями будут все клиенты с рассылками.
2. Задайте дату не раньше чем через 2 минуты. Отправка начинается в течение минуты после указанного времени.
3. Введите до 4000 символов. Выберите Markdown или HTML, то есть способ форматирования текста Telegram, и проверьте «Показать превью». Некорректную разметку форма не сохранит.
4. При необходимости добавьте изображение до 10 МБ: SVG, PNG, JPEG, GIF, WebP, BMP или HEIC.
5. Нажмите «Сохранить», проверьте аудиторию и канал в подтверждении, затем нажмите «Да».
6. Чтобы отправить запланированное сообщение раньше, выберите «Отправить сейчас» и подтвердите.

Изменить и отменить можно только рассылку в статусе «Запланирована». При выборе RFM-сегментов точка обязательна; если у старой запланированной рассылки её нет, укажите через «Изменить», иначе отправка завершится неудачей. Сохранённые аудитории из [Аналитика → Сегменты](segments.md) в рассылках не используются.

### Особенности письма { #email-behavior }

Первая строка становится темой и заголовком, до 100 символов. HTML сохраняет форматирование, Markdown приходит как текст без преобразования. Tellem добавляет оформление и подвал. Без текста письмо не отправляется.

## Проверить результат { #results }

| Статус | Что означает и что делать |
| --- | --- |
| «Запланирована» | Ждёт даты; можно изменить, отменить или отправить сейчас |
| «Рассылается» | Идёт отправка; дождитесь результата |
| «Отправлено» | Каждый канал принял сообщение хотя бы для одного клиента; это не подтверждение прочтения |
| «Отменена» | Отменена вручную либо ни у кого нет доступного канала |
| «Неудача» | Ни один канал не принял сообщение или не пройдена проверка перед отправкой |
| «Отправлено частично» | Часть каналов приняла сообщение, часть нет |
| «Результат неизвестен» | VK не подтвердил приём; сообщение могло дойти. Повтор заблокирован |

«Повторить» открывает копию сообщения с изображением, форматом, сегментами и точкой для редактирования. После частичной отправки повтор продублирует сообщения в каналах, которые уже приняли их. Проверьте результат до повторной отправки.

## Создать с AI { #ai }

Для подготовки текста с помощью искусственного интеллекта подключите [интеграцию AI](integrations.md#ai), затем нажмите «Создать с AI». Выберите цель, при необходимости сегменты и точку, добавьте пожелания до 1000 символов и нажмите «Сгенерировать».

При выбранных сегментах точка обязательна; такой выбор заменит аудиторию основной формы. Для текста AI использует сведения о магазинах, каталоге, популярных товарах, действующих акциях и промокодах, включая коды. Перед сохранением проверьте текст, цены, условия и аудиторию по данным CRM.
