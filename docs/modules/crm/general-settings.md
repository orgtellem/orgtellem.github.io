# Основные настройки, поддержка и PWA { #general-settings }

Настройте поведение каталога, сообщения покупателям и контакты поддержки. На экранах **Основные** и **PWA** большинство изменений сохраняется сразу.

<span id="_1"></span>

## Основные { #general }

Откройте **Настройки → Основные**.

- Выберите страну до создания магазинов и заказов: после этого изменить её нельзя.
- Укажите сортировку каталога. При **Автоматическом создании ассортимента** новый товар появляется во всех магазинах с нулевым количеством. Показ закончившихся товаров настройте по [инструкции о наличии](inventory.md).
- Включите **Бронирование товаров**, если нужно удерживать товары в корзине. Укажите время неактивности покупателя, после которого корзина очищается. **Резервировать товары вместо покупки** позволяет принимать бронирования без оплаты заказа.
- При необходимости включите подтверждение совершеннолетия при открытии приложения.
- Включите **Мультиязычный редактор**, чтобы вводить названия и описания на языках приложения. При выключенной настройке покупатели видят один текст.

### Предупреждение для клиентов магазина { #customer-notice }

Создайте сообщение, например о задержке заказов, и выберите сеть. Его увидят только вошедшие покупатели этой сети. Для включения используйте **Активно** в таблице: этот переключатель отключает остальные предупреждения сети. Переключатель в карточке предупреждения этого не делает.

<span id="additional-information-in-the-customer-profile"></span>

### Дополнительная информация для профиля пользователя { #profile-sections }

Добавьте раздел с названием и содержанием, например правила магазина. Включите **Публичный раздел**, чтобы его видели и гости; иначе раздел доступен только вошедшим покупателям.

<span id="_4"></span>

## Поддержка { #support }

Откройте **Настройки → Поддержка → Добавить контакт**. Выберите аккаунт сотрудника, укажите отображаемое имя и описание. Сотрудник должен заранее войти в приложение; один аккаунт можно добавить один раз.

Покупатели видят контакт в профиле и заказах: имя, описание и доступные значки Telegram и почты. Телефон контакта покупателям не показывается. Пока контактов нет, приложение скрывает пункт **Поддержка**.

Контакты с Telegram также получают сообщения об ошибках заказов iiko. Отдельно настройте [получателей уведомлений CRM](crm-notifications.md#seller-recipients).

## PWA { #pwa-settings }

PWA — приложение, которое покупатель [устанавливает из браузера](../app/account.md). В **Настройки → PWA** задайте:

- **Название приложения** длиной до 64 символов. Если поле пусто, используется имя поддомена магазина, а при его отсутствии — Tellem.
- **Иконку** в формате PNG до 2 МБ. Используйте квадратное изображение от 512×512 пикселей.

На уже установленных устройствах название и значок обновляются с задержкой.
