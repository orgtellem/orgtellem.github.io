# Первый промокод для нового магазина { #first-promo-code-for-a-new-store }

В примере кофейня предлагает покупателю код DEMO250: «Айс капучино» стоит 250 вместо 300 руб. Скидка составляет 50 руб. за единицу товара.

Где: **Маркетинг → Промокоды**. Сначала [создайте товар](products-and-categories.md#products), задайте обычную цену и [наличие](inventory.md#by-store).

!!! note "Ограничение на одно использование не проверяет первый заказ"
    Лимит клиента 1 разрешает один заказ с этим кодом. Если покупатель не ввёл его при первой покупке, код останется доступен для следующей. Выдайте код до первой покупки и укажите это условие в предложении.

## 1. Задайте код и ограничения { #1-set-the-code-and-limits }

Нажмите «Создать» и заполните поля для примера:

| Поле | Значение |
| --- | --- |
| «Название промокода» | Демо: Айс капучино за 250 ₽ |
| «Статус» | «Активна» |
| «Дата начала» | Текущие дата и время |
| «Дата окончания» | Пусто для бессрочного кода либо дата окончания предложения |
| «Код для покупателя» | DEMO250; регистр важен |
| «Общее число использований» | Пусто, без общего лимита |
| «Число использований клиентом» | 1 |

Общий лимит 1 разрешил бы только одно использование во всём магазине. Для одного использования каждым покупателем оставьте общий лимит пустым.

## 2. Выберите товар и конечную цену { #2-select-the-product-and-final-price }

1. В «Скидка и товары» выберите «Фиксированная цена».
2. Через **Добавить товары → Выбрать из списка** выберите товар. В примере это «Айс капучино» за 300 руб.
3. В «Цена по промокоду» введите 250 и перейдите к другому полю. В таблице выбранного товара проверьте конечную цену 250 руб.

Для своего товара вычтите скидку из обычной цены. Результат должен быть не меньше 1 руб. Значение 50 в поле цены означало бы продажу за 50 руб.

!!! note "Укажите условия предложения"
    В примере скидка составляет 50 руб. за каждую единицу выбранного товара: две единицы дают 100 руб. Остальные товары сохраняют обычную цену. Это не фиксированная скидка 50 руб. на произвольную корзину. Укажите товар и правило количества рядом с предложением.

## 3. Сохраните и проверьте { #3-save-and-check }

Проверьте код, активный статус, выбранный товар, цену и лимит клиента 1, затем нажмите «Сохранить».

В приложении добавьте одну единицу товара и примените DEMO250 при [оформлении](../app/checkout.md). В примере цена станет 250 руб.

Для проверки достаточно применить код до подтверждения заказа. Создание заказа расходует использование; отмена его не возвращает. Для повторных проверок возьмите отдельного тестового покупателя или тестовый код.

Чтобы остановить предложение, откройте промокод, выберите «Завершена» и сохраните. Общие [правила цен и ограничений](promo-codes.md#promo-codes) описаны отдельно.
