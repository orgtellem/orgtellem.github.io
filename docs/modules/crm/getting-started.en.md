# Store launch checklist { #store-launch-checklist }

Set up your store in this order, then place a test order. Create fulfillment and payment methods under **Settings** first, then enable them for the store. Set stock separately for each location.

1. **Sign in to the CRM** and complete **Welcome configuration**: [connection and first sign-in](../../getting-started/registration.md).
2. **Settings → General.** Check the country before creating your first store or order; it becomes locked afterwards. [General store settings](general-settings.md).
3. **Settings → Delivery.** Choose the required fulfillment methods or connect a carrier: [delivery and pickup setup](delivery.md).
4. **Settings → Payments.** Choose payment on receipt or add online payment using **New service**. Check it with **Generate a test payment link**; enable it for the store after a successful test payment. [Connecting payments](payment-providers.md).
5. **Catalog → Stores.** Create a store or store chain and enable fulfillment and payment methods. Without an available fulfillment method, customers cannot place orders. [Store setup](stores-and-delivery.md).
6. **Catalog → Categories and Products**, or **Import**. [Add the catalog manually](products-and-categories.md) or [import a file](catalog-import.md).
7. **Catalog → Inventory.** Set quantities at each location; customers see products with no stock as **Out of stock**. [Managing stock](inventory.md).
8. **Catalog → Design.** Set up [the home screen and app colors](main-page.md).
9. **Settings → Notifications.** Add new-order recipients and select their stores; without a selected store, notifications will not arrive. Employees need an app account to appear in **Clients**. [Employee notifications](crm-notifications.md).
10. **Integrations, optional.** Connect a [Telegram bot](../../getting-started/bot-setup.md), [VK community](vk.md), or [iiko](iiko.md) if you plan to use them.
11. **Place a test order.** Open **Go to app** in the user menu and choose payment on receipt. In the CRM, open **Orders**, find the **New** order, and click **Accept order**. Check that the employee received a notification. [Processing an order](orders.md).

If the app shows **Ordering is unavailable**, return to store settings in step 5 and check fulfillment methods. For a launch offer, [create your first promo code](first-promo-code.md).
