# Поля в заказе { #order-fields }

Настройте, какие данные покупатель вводит в профиле и при оформлении заказа.

Откройте **Настройки → Поля Заказа**.

<span id="_2"></span>

## Поля адреса клиента { #customer-address-fields }

Укажите, какие части адреса видны и обязательны. Изменения сохраняются сразу и действуют в профиле и при оформлении. Страну, город и улицу скрыть нельзя. Обязательное поле всегда видно; скрытое поле не может быть обязательным.

<span id="order-fields-by-payment-method"></span>

<span id="_3"></span>

## Поля заказа для способа оплаты { #payment-method-fields }

Имя, фамилию, телефон и почту настройте отдельно для каждого способа: **Перейти к способам оплаты → нужный способ → Поля заказа**. Требования платёжного сервиса могут делать поле обязательным: см. [настройку оплаты](payment-providers.md).

<span id="_4"></span>

## Дополнительные поля заказа { #additional-order-fields }

1. Нажмите **Создать** и выберите, к чему относится поле: **Способ получения** для всего заказа или **Вариант товара** для выбранных товаров. Для первого варианта обязательно выберите способ получения.
2. Выберите тип поля. Для выпадающего списка добавьте хотя бы два значения.
3. Задайте уникальное наименование латинскими буквами и цифрами и порядок отображения больше нуля. Интеграционный ключ оставьте пустым, если он не нужен подключённой интеграции. После подключения интеграции не меняйте уникальное наименование.
4. Сохраните поле и проверьте его на [экране оформления заказа](../app/checkout.md).

!!! warning "Конфиденциальные данные"
    Этот признак действует только для полей **Вариант товара**. После завершения, отмены, возврата заказа или ошибки оплаты CRM заменяет значения на **DELETED**. Учитывайте это, если данные понадобятся после обработки заказа.
