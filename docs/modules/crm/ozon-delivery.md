# Доставка Ozon

Tellem рассчитывает предварительные стоимость и срок доставки в ПВЗ Ozon. Покупатель выбирает пункт выдачи при оформлении заказа; его название и адрес сохраняются в карточке заказа.

## Подключение

1. В личном кабинете Ozon Доставки для бизнеса создайте метод доставки: укажите, в какой пункт Ozon будете передавать отправления. Сохраните идентификатор метода.
2. В разделе управления частными приложениями Ozon создайте приложение с доступами `delivery-api.delivery`, `delivery-api.delivery-point` и `delivery-api.order`. Скопируйте Client ID и Client Secret.
3. В CRM откройте **«Настройки → Доставка»**, нажмите **«Создать → Ozon»** и заполните название, данные приложения и идентификатор метода отгрузки.
4. Укажите размеры упаковки и вес товара по умолчанию. Вес заказа считается по товарам и их количеству; запасной вес используется для товаров без своего веса. Расчёт выполняется для одной коробки.
5. Сохраните настройку. В **«Каталог → Магазины»** откройте нужный магазин или сеть и включите способ в блоке **«Управление способами получения»**.

Новый способ не включается для покупателей автоматически. Для разных точек отгрузки создайте отдельные настройки. Client Secret хранится зашифрованным.

Для кнопки «Проверить подключение» дополнительно укажите проверочный телефон, зарегистрированный на Ozon, и идентификатор ПВЗ назначения. Проверка рассчитывает доставку дефолтной коробки с объявленной стоимостью 1 ₽; отправление не создаётся. Эти данные нужны только для проверки и не заменяют данные покупателя.

## Оформление заказа

Для Ozon нужен телефон получателя, зарегистрированный на Ozon. Покупатель выбирает адрес для определения города, затем пункт выдачи из списка. Можно искать ПВЗ по названию и адресу. При смене адреса пункт нужно выбрать заново.

Стоимость включает предварительную цену доставки и страховки. Объявленная стоимость рассчитывается по сумме товаров заказа. Тариф Ozon после приёмки может отличаться от предварительного расчёта, если фактические параметры отправления отличаются.

Первичная загрузка списка ПВЗ может занять время. Если список ещё загружается, повторите запрос позже. Закрытые пункты и постаматы не показываются.

Если Ozon отклонил доставку, нужно исправить данные получателя или выбрать другой способ. До успешного расчёта оформить заказ с доставкой Ozon нельзя.

## Обработка отправления

Интеграция пока не создаёт отправления в Ozon, не подтверждает отгрузку, не скачивает этикетки и не отслеживает статусы перевозчика. Эти операции выполняются отдельно в личном кабинете Ozon. Постаматы в этой версии не подключены.

Курьерская доставка Ozon пока недоступна: её API требует координаты, а Tellem не переводит введённый адрес в координаты. Для Ozon используется только выбор ПВЗ из списка.

Обычная обработка заказа в Tellem описана в разделе [«Работа с заказами»](orders.md).
