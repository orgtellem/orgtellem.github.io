# Клиенты

Покупатели магазина: найдите клиента, свяжитесь с ним, посмотрите его заказы, бонусы и адреса.

Где: **Клиенты**. Клиента нельзя создать или удалить вручную: он появляется сам из действий покупателя в приложении.

## Список

- Поиск ищет по имени, фамилии, отчеству, Telegram-юзернейму и почте. По телефону он не ищет: для этого есть фильтр в заголовке колонки.
- Остальные фильтры тоже в заголовках колонок. Кнопка Excel выгружает таблицу, шестерёнка меняет набор колонок. По умолчанию на странице 100 клиентов.

## Связаться

Выберите клиента и откройте «Связаться»:

- «Телеграм» открывает чат с клиентом, если у него есть Telegram-юзернейм;
- «Эл. почта» отправляет письмо из CRM, если почта клиента подтверждена. Первая строка текста станет темой письма. Если на платформе не настроена отправка почты, появится «Не удалось поставить письмо в очередь».

Для писем многим клиентам сразу используйте [«Рассылки»](mass-mailings.md). Кнопки связи в карточке клиента только открывают чат Telegram и вашу почтовую программу (для любого адреса, не только подтверждённого), а письмо через CRM отправляется из списка.

## Карточка клиента

Откройте её кнопкой редактирования. «Показать заказы» открывает сразу вкладку «Заказы». Изменения применяются при сохранении карточки.

- **«Основное»**. «Контактная информация» (имя, фамилия, юзернейм, телефон, почта) и «Прочее» (зона продаж, язык, последняя активность, дата регистрации) — только просмотр: контакты покупатель меняет сам в приложении. В «Доступ → Права» можно снять «Заказ с доставкой» или «Заказ с самовывозом» — тогда при оформлении у клиента скрыты все способы этого типа, включая перевозчиков («Онлайн» и «В заведении» доступны всегда). «Просмотр каталога» пока ни на что не влияет.
- **«Заказы»** — дата, номер, статус и сумма. Обработка заказа — на странице [«Заказы»](orders.md).
- **«Бонусы»** — есть, только если в CRM включена бонусная система. Показывает аккаунт бонусной системы (Tellem или MAXMA), баланс, ближайшее сгорание («Сгорят N бонусов: дата») и историю операций с номерами заказов. Если у клиента нет аккаунта, вместо баланса — «Пользователь не зарегистрирован в бонусной системе». Баланс вручную меняется только в бонусной системе Tellem; изменение записывается как «Ручная корректировка бонусов». Правила начисления и сгорания — в [«Маркетинг → Бонусы»](bonus-system.md).
- **«Адреса доставки»** — есть, если покупатель сохранил адрес. Только просмотр: адреса ведёт сам покупатель.

Сегменты и показатели по клиентам — в разделе [«Аналитика»](analytics.md).
