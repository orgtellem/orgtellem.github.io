# Клиенты { #customers }

Найдите покупателя, свяжитесь с ним или проверьте его заказы и бонусы.

Где: **Клиенты**. Покупатель появляется в списке после действий в приложении; создать или удалить его вручную нельзя.

## Найти и связаться { #find-and-contact-a-customer }

Введите запрос и нажмите Enter: поиск работает по имени, фамилии, отчеству, имени пользователя Telegram и почте. Для телефона используйте фильтр в заголовке колонки. Кнопка Excel выгружает таблицу.

Откройте портрет клиента и нажмите «Связаться» рядом с именем: откроется Telegram, а если у клиента нет имени пользователя Telegram — ваша почтовая программа. Если доступны оба канала, письмо открывает соседняя кнопка с конвертом. Для письма можно использовать и неподтверждённую почту. Для сообщения нескольким клиентам используйте [рассылки](mass-mailings.md).

## Карточка клиента { #customer-record }

Нажмите строку клиента или выделите её и нажмите Enter, чтобы открыть портрет клиента. На широком экране он появится в панели «Клиент» справа поверх таблицы, сохраняя её ширину; на небольшом экране — в диалоге «Портрет клиента».

На широком экране потяните левую границу панели, чтобы изменить её ширину. Выбранная ширина сохраняется при переходе к другому клиенту и повторном открытии портрета, а после выхода из раздела — до следующего посещения.

Закройте портрет крестиком; панель «Клиент» закрывается и клавишей Escape. Если вы меняли данные, перед закрытием или выбором другого клиента подтвердите сохранение или отмену изменений.

При открытии портрета из аналитического списка CRM сохраняет точки и период отчёта. Если вы открыли портрет из отчёта по конкретной точке, CRM оставляет её выбранной. Иначе CRM выбирает точку с наибольшей суммой оценок R + F + M из [сохранённого расчёта](analytics.md#rfm) среди доступных вам точек с учётом фильтра точек отчёта. Единственную точку CRM выбирает и без оценки; при нескольких точках без оценок выберите её вручную.

Над вкладками видны RFM-сегмент, число завершённых покупок за всё время, их сумма и дни без покупки. Цвет всей сводки соответствует сегменту в [аналитике](analytics.md#rfm). При отсутствии покупок карточка сообщает об этом без нулевых показателей. Выберите точку в сводке, чтобы посмотреть её показатели.

[![Выбор точки, ритм покупок, заказы и история кампаний в карточке клиента](../../media/crm/client-profile-campaigns.gif){ loading=lazy width=720 height=900 }](../../media/crm/client-profile-campaigns.gif)

Контакты и адреса доступны только для просмотра: покупатель меняет их в [профиле приложения](../app/account.md). На вкладке «Права» можно отключить заказы с доставкой или самовывозом. Покупатель перестанет видеть все способы выбранного типа, включая перевозчиков. «Онлайн» и «В заведении» останутся доступны; «Просмотр каталога» на доступ не влияет.

«[имя пользователя недоступно]» в контакте Telegram означает, что у покупателя привязан Telegram, но имя пользователя недоступно. По этой подписи нельзя судить, получает ли он сообщения бота. Прочерк означает, что Telegram не привязан.

Во вкладке «Заказы» видна история заказов клиента. Чтобы обработать заказ, найдите его по номеру в [разделе «Заказы»](orders.md).

### Профиль покупок { #purchase-profile }

Во вкладке **«Профиль»** посмотрите **«Ритм покупок»**: клиент покупает в привычном ритме, его пора пригласить или он давно не покупал. Рядом указаны последняя покупка и обычный интервал клиентов выбранной точки. Это ориентир точки, а не личный график клиента. При недостатке данных оценка недоступна.

Предпочтения по дням, времени, товарам и способу получения появляются, когда история позволяет их определить. Если число покупок точки отличается от RFM-сводки, оно указано отдельно. Показатели исторического отчёта не перезаписывают текущий маркетинговый профиль.

### Кампании { #campaigns }

Выберите точку в сводке и откройте **«Кампании»**. Выберите строку и нажмите **«Открыть кампанию»**, чтобы посмотреть исходные параметры и сообщение.

Здесь вы увидите участие в аудитории на момент запуска. Отписки, новые заказы и изменения сегмента не меняют историю; участие не подтверждает доставку или прочтение. Правила запуска и повторения описаны в [кампаниях и рассылках](mass-mailings.md).

### Бонусы { #bonuses }

Вкладка «Бонусы» доступна при включённой бонусной системе. В ней можно проверить баланс, ближайшее сгорание и историю операций. Если покупатель не подключил программу, баланса нет. Вручную менять баланс можно только для Tellem; в истории появится «Ручная корректировка бонусов». Правила расчёта и сгорания находятся в [бонусной системе](bonus-system.md).

### День рождения { #birthday }

Укажите или измените день и месяц без года, затем сохраните карточку до начала периода подарка. Удалённую вручную дату приложение не заполнит повторно из внешнего сервиса. Условия подарка покупатель увидит в [профиле](../app/account.md#birthday).

Если в «Подарок в день рождения» выбраны «Бонусы в день рождения», владелец или администратор может компенсировать пропущенные бонусы кнопкой «Компенсировать подарок в день рождения» на вкладке «Профиль» в блоке контактов. Перед подтверждением проверьте [условия компенсации](bonus-system.md#birthday-compensation).

Для выбора аудитории по покупкам откройте [сегменты](segments.md); для показателей по клиентам используйте [аналитику](analytics.md#rfm).
