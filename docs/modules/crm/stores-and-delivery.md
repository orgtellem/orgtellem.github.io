# Магазины { #stores }

Создайте точки продаж, включите способы получения и оплаты, затем поделитесь ссылкой или QR-кодом магазина.

Откройте **Каталог → Магазины**.

<span id="_2"></span>

## Магазин или сеть { #store-or-chain }

Нажмите **Создать**; на телефоне — **Действия → Создать**. Выберите **Один магазин** для одной точки или **Сеть магазинов** для точек с общими способами получения и оплаты.

- У магазина заполните название, город и улицу. Склад и пункт выдачи создаются вместе с магазином; добавьте товары через [Наличие](inventory.md).
- В сеть добавьте хотя бы один магазин. **Добавить магазин** выбирает существующий; **Создать** в окне выбора добавляет новый. Магазин может входить в несколько сетей; его название должно быть уникальным внутри сети.
- Статус **Временно закрыта** оставляет сеть в списке у покупателя, скрывая её товары. Поле **Сообщение о закрытии сети магазинов** в приложении не отображается. Статус **Помещена в архив** скрывает сеть целиком.

## Способы получения { #fulfillment-methods }

В **Управление способами получения** включите нужные способы. Создайте недостающие в [Настройки → Доставка](delivery.md).

!!! warning "Ограничения способов"
    Без включённого способа покупатель не сможет оформить заказ. **Онлайн** несовместим с другими способами: включение одного отключает другой. В сети с **Онлайн** может быть только один магазин.

<span id="_4"></span>

## Способы оплаты { #payment-methods }

В **Управление способами оплаты** включите сервисы, созданные в [Настройки → Оплата](payment-providers.md). В новой сети уже включены **Наличными при получении** и **Картой при получении**. Два способа одного типа, например две настройки ЮKassa, одновременно включить нельзя.

## QR-код и ссылка { #qr-links }

Выберите строку магазина или сети и нажмите **Распечатать QR-код**. Проверьте **Точка продаж** в окне печати. Распечатайте код или нажмите **Копировать ссылку**, чтобы разместить её на сайте и в соцсетях. Ссылка открывает выбранный магазин в браузере; Telegram не нужен.

## Удаление { #deletion }

Магазин или сеть с заказами удалить нельзя. У одиночного магазина сначала обнулите остатки или удалите строки в [Каталог → Наличие](inventory.md). Вместе с ним удаляются его склад и пункт выдачи.
