# Магазины

Точки продаж, которые выбирает покупатель: одиночный магазин или сеть магазинов. Здесь же включаются способы получения и оплаты и берутся QR-код и ссылка на магазин.

Где: **Каталог → Магазины**.

## Магазин или сеть

«Создать» → «Магазин» (одна точка) или «Сеть магазинов» (несколько точек с общими способами получения и оплаты).

- У магазина обязательны название, город и улица; «Номер дома» можно не заполнять. Склад и пункт выдачи создаются вместе с магазином сами; товары в него добавляют в [«Наличие»](inventory.md).
- В сети должен быть хотя бы один магазин. «Добавить магазин» выбирает уже созданные (в окне выбора «Создать» заводит новый), один магазин может входить в несколько сетей. Название магазина уникально внутри сети.
- «Статус» есть только у сети. «Временно закрыта» оставляет сеть в списке у покупателя, но товары в каталоге не показываются; текст из поля «Сообщение о закрытии сети магазинов» в приложении пока не выводится. «Помещена в архив» скрывает сеть от покупателей.

## Способы получения

Блок «Управление способами получения»: переключатель на каждый способ из «Настройки → Доставка»; карандаш рядом с заголовком открывает эти настройки. Свои способы и перевозчиков создают в разделе [«Доставка»](delivery.md).

- «Онлайн» нельзя сочетать с другими способами: включение «Онлайн» выключает остальные, включение любого другого выключает «Онлайн». В сети с «Онлайн» может быть только один магазин.
- Без включённого способа покупатель не сможет оформить заказ. Магазин или сеть без способов получения CRM сохранит только после предупреждения.

## Способы оплаты

Блок «Управление способами оплаты»: переключатель на каждый сервис из «Настройки → Оплата» ([Оплата](payment-providers.md)). Сначала создайте сервис там, затем включите его здесь. В новой сети уже включены «Наличными при получении» и «Картой при получении». Два способа одного типа (например, две настройки ЮKassa) в сети включить нельзя.

## QR-код и ссылка

«Распечатать QR-код» в списке открывает окно «Печать QR-кода». Если строка выделена, заведение выбрано заранее, иначе выберите его в поле «Заведение». Кнопка «Распечатать QR-код» печатает код, «Копировать ссылку» копирует адрес для сайта и соцсетей. Ссылка открывает приложение в браузере сразу с этим магазином; Telegram не нужен. Для магазина с iiko в окне можно выбрать стол, а «QR для всего заведения» вернёт общий код: [iiko](iiko.md).

## Удаление

«Удалить» не сработает, если по магазину или сети есть хотя бы один заказ. Одиночный магазин с ненулевым остатком тоже не удалится: обнулите остатки или удалите строки в [«Каталог → Наличие»](inventory.md). Вместе с одиночным магазином удаляются его склад и пункт выдачи.
