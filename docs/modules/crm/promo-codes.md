# Промокоды

Промокод — это скидка на выбранные вами товары, которую покупатель получает, введя кодовое слово при оформлении
заказа. Пока код не введён, скидка нигде не видна: в каталоге и в корзине товары отображаются по обычной цене.
Этим промокод отличается от акции — акционные цены видит каждый покупатель, а цену по промокоду только тот, кому
вы передали код.

Промокоды удобны для рассылок, партнёрских размещений и работы с отдельными клиентами: у каждого кода есть срок
действия, общий лимит применений и лимит на одного покупателя.

Управление промокодами — в разделе меню «Маркетинг → Промокоды».

## 1. Экран «Промокоды»

Список всех промокодов с колонками «Статус», «Наименование», «Код», «Дата начала», «Дата окончания»,
«Общее число использований», «Число использований клиентами». У промокода без даты окончания в колонке
«Дата окончания» отображается «Бессрочно».

Две последние колонки легко спутать: «Общее число использований» — это заданный вами лимит, а
«Число использований клиентами» — сколько раз код уже применили.

Кнопка «Создать» открывает создание нового промокода, «Изменить» — редактирование выбранного.

!!! note
    Удалить промокод с этого экрана нельзя — кнопки удаления здесь нет. Чтобы прекратить действие промокода,
    переведите его в статус «Завершена».

## 2. Создание промокода

Нажмите «Создать» — откроется экран «Промокод».

**Основные поля:**

- «Наименование» — название промокода, до 20 символов. Обязательное поле. По нему вы находите промокод в списке;
  в карточке заказа название показывается вместе с кодом.
- «Код» — кодовое слово, которое вводит покупатель. Обязательное поле. Код уникален: при попытке сохранить
  второй промокод с тем же кодом появится сообщение «Промокод с данным кодом уже существует».
- «Статус»:
    - «Запланирована» — промокод станет активным автоматически в дату начала;
    - «Активна» — покупатели могут применить код при оформлении заказа;
    - «Завершена» — действие промокода прекращено.
- «Дата начала» — момент, когда промокод автоматически станет активным. В календаре доступно время начиная с
  ближайшего целого часа.
- «Дата окончания» — момент, когда промокод автоматически завершится. Под полем подсказка «Оставьте поле пустым,
  если требуется бессрочная акция»: без даты окончания промокод действует до ручного перевода в статус «Завершена».
- «Общее число использований» — лимит применений всеми покупателями. Пустое поле означает, что ограничения нет.
- «Число использований клиентом» — лимит применений для одного покупателя. По умолчанию 1. Пустое поле означает,
  что ограничения нет.

Новый промокод создаётся в статусе «Запланирована». Статус переключается по датам автоматически, проверка
выполняется каждую минуту. Статус можно выставить и вручную: поставьте «Активна», чтобы промокод заработал сразу,
не дожидаясь даты начала, или «Завершена», чтобы прекратить его действие досрочно.

**Товары и размер скидки:**

Промокод даёт скидку на товары, а не на сумму заказа, и действует только на те товары, которые добавлены в таблицу
в нижней части экрана.

1. Выберите тип изменения цены:
    - «Изменение на процент» — цена по промокоду равна «Цене продажи» товара минус указанный процент. Введите
      процент от 1 до 99 в поле «Введите процент». Результат считается для каждого товара и виден в колонке
      «Цена по акции».
    - «Фиксированная цена» — вы задаёте новую цену товара. Введите её в поле «Введите новую цену» (не меньше 1)
      или задайте цену отдельного товара прямо в таблице, в колонке «Фиксированная цена».
2. Нажмите «Добавить товары» и выберите способ:
    - «Выбрать из списка» — отдельные товары;
    - «Из категории» — все товары выбранной категории.
3. Лишние строки выделите в таблице и нажмите «Удалить». Счётчик «Товаров: N» показывает размер списка.
4. Нажмите «OK», чтобы сохранить промокод, или «Отмена», чтобы закрыть экран без сохранения.

Значение из поля «Введите процент» или «Введите новую цену» применяется ко всем товарам таблицы сразу, включая
те, которые вы добавите после. Разные цены для разных товаров задаются только при типе «Фиксированная цена» —
редактированием строк в таблице. При выбранном типе «Изменение на процент» редактирование строки заблокировано,
появляется сообщение «Указание фиксированной цены не доступно, пока выбрано изменение цены на процент».

**Проверки при сохранении:**

- В промокоде должен быть хотя бы один товар — иначе появится сообщение «Добавьте хотя бы один товар для участия
  в акции».
- Дата окончания не может быть раньше даты начала — сообщение «Дата окончания не может быть раньше даты начала».
- При типе «Фиксированная цена» цена должна быть заполнена у каждого товара — сообщение «У одного из товаров не
  заполнено поле "Фиксированная цена"».
- Открытое редактирование строки в таблице нужно закрыть — сообщение «Для продолжения закройте редактирование
  строки в таблице».

!!! warning
    Скидка применяется, только если цена по промокоду ниже обычной «Цены продажи» товара. Если задать цену выше
    обычной, цена этого товара в заказе не изменится.

## 3. Лимиты использований

- Использование засчитывается в момент оформления заказа с промокодом.
- Когда число применений достигает значения из поля «Общее число использований», промокод автоматически
  переходит в статус «Завершена» и перестаёт применяться.
- «Число использований клиентом» считается для каждого покупателя отдельно: со значением по умолчанию каждый
  покупатель применяет код один раз.
- Текущее число применений видно в списке промокодов в колонке «Число использований клиентами».

!!! note
    Отмена заказа не возвращает использование: заказ с промокодом учитывается в лимитах независимо от его
    дальнейшего статуса.

## 4. Промокод и акции {#promo-codes-and-sales}

Промокод не суммируется со скидками из раздела «Маркетинг → Акции». Если покупатель применил промокод:

- товары из промокода продаются по цене промокода;
- остальные товары заказа продаются по обычной цене — акционные скидки в этом заказе не действуют.

Если промокод не применён, заказ считается по акционным ценам как обычно.

!!! tip
    Не выдавайте промокоды на товары, которые уже участвуют в акции: покупатель получит скидку по промокоду
    вместо акционной, а по остальным товарам заказа потеряет акционную цену.

## 5. Как промокод применяет покупатель

Промокод вводится на экране оформления заказа — в корзине поля для него нет.

1. Покупатель выбирает товары в корзине и нажимает «Оформить заказ на <сумма>».
2. На экране «Оформление заказа» в блоке «Промокод» вводит код в поле «Введите промокод» и нажимает круглую
   кнопку со стрелкой рядом с полем.
3. После применения поле блокируется. Убрать код можно крестиком в поле.
4. Скидка видна в блоке «Детали стоимости»: строка «Товары» — сумма без скидок, строка «Скидка» — размер скидки
   со знаком минус, «Итого» — сумма к оплате. Если бонусная система включена, там же есть строка «Начислим
   бонусов» — она пересчитывается от суммы со скидкой по промокоду.

Пробелы по краям кода отбрасываются автоматически, а регистр важен: код нужно ввести ровно так, как он задан
в CRM. Промокод применяется только к тем позициям корзины, которые покупатель отправил в оформление.

**Сообщения об ошибке под полем промокода:**

| Сообщение | Причина |
|---|---|
| «Такого промокода не существует...» | Код введён с опечаткой или в другом регистре, либо промокод не в статусе «Активна»: ещё «Запланирована», уже «Завершена» по дате окончания или исчерпан общий лимит. |
| «К сожалению, данный промокод достиг максимального лимита по использованиям» | Достигнут лимит «Общее число использований». |
| «К сожалению, Вы уже использовали данный промокод» | Покупатель исчерпал свой лимит «Число использований клиентом». |
| «Промокод не подошёл» | Промокод действует, но ни один из оформляемых товаров в него не входит. |

Те же три проверки — существование активного промокода, общий лимит и лимит на покупателя — выполняются повторно
в момент создания заказа. Если между применением кода и подтверждением заказа промокод завершился или лимит
исчерпал другой покупатель, заказ не создастся и покупатель увидит то же сообщение.

## 6. Где увидеть применённый промокод

В карточке заказа в CRM появляется блок «Промокод» с названием и кодом. Нажатие на него открывает карточку самого
промокода — так вы проверяете условия, по которым заказ получил скидку.

## 7. Промокоды в рассылках

Активные промокоды передаются в контекст AI-генерации текста рассылки на экране «Маркетинг → Рассылки»: название,
код, лимит на покупателя, срок действия и цены по товарам. Сгенерированный текст перед отправкой всегда проверяйте
— код в письме должен совпадать с кодом в CRM.

!!! note
    Краткая справка по промокодам есть и внутри CRM: раздел меню «Помощь», блок «Маркетинг» → «Промокоды».
