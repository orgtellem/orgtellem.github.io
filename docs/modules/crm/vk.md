# VK: подключение сообщества

Сообщество магазина отправляет покупателям сообщения о статусе заказа и информационные рассылки в личный диалог VK.

Где: **Интеграции → VK**. Настройку выполняет владелец CRM или полный администратор.

## 1. Подготовьте сообщество

Откройте VK в браузере под аккаунтом администратора сообщества магазина.

1. В сообществе выберите **«Управление → Сообщения»**.
2. Включите **«Сообщения сообщества»** и сохраните изменение.
3. Перейдите в **«Управление → Дополнительно → Работа с API → Ключи доступа»**.

![Работа с API: вкладка «Ключи доступа» и кнопка «Создать ключ»](../../media/vk-setup/vk-access-keys.png)

4. Нажмите **«Создать ключ»**. Отметьте только **«Разрешить приложению доступ к сообщениям сообщества»** и нажмите **«Создать»**. Если VK попросит подтверждение, завершите его.

![Создание ключа: выбран только доступ к сообщениям сообщества](../../media/vk-setup/vk-key-permissions.png)

5. Вернитесь к списку ключей, нажмите **«Показать»** и скопируйте новый ключ целиком.

В некоторых версиях VK «Работа с API» находится сразу в меню управления. Если сообщества ещё нет, сначала создайте его. Подробнее — [инструкция VK](https://habr.com/ru/companies/vk/articles/570486/).

!!! warning "Ключ — секрет"
    Вставляйте его только в CRM. Не отправляйте покупателям и не публикуйте на скриншотах.

## 2. Подключите в CRM

1. Откройте **«Интеграции → VK»**.
2. Включите переключатель рядом с **«Сообщество VK»** — появятся поля подключения.
3. Вставьте ключ в **«Ключ доступа сообщества»** и выйдите из поля.
4. Дождитесь **«Подключено: …»** и проверьте название сообщества.

Настройки сохраняются автоматически, отдельной кнопки «Сохранить» нет. CRM определяет сообщество по ключу; вводить его ID не нужно. **«Проверить подключение»** повторяет проверку. Проверка не отправляет покупателям сообщений.

![Экран подключения сообщества VK в CRM](../../media/vk-setup/crm-connection.png)

Для этой интеграции не требуется настройка Callback API, Long Poll API или отдельного сервера. Вход через VK ID и ключ сообщества настраиваются отдельно: ключ нужен для сообщений.

## 3. Подключите уведомления покупателю

Ключ разрешает магазину отправку, но каждый покупатель должен отдельно разрешить сообщения сообщества. После входа через VK ID или привязки VK приложение предлагает **«Уведомления в VK»**. Покупатель подтверждает разрешение прямо в этом окне.

Покажите ему [инструкцию с экранами подключения](../app/customer-notifications.md#vk). Подписываться на новости сообщества для уведомлений о заказе не требуется.

После подключения уведомления о заказе используют один доступный канал: **Telegram → VK → e-mail**. Если Telegram уже доступен, сообщение о заказе придёт туда. Push, включённые на устройстве, приходят дополнительно. Для информационных рассылок нужен включённый переключатель «Рассылки» — [как отправить рассылку](mass-mailings.md).

## Если подключение не удалось

| Что видно | Что сделать |
|---|---|
| «Ключ недействителен или отозван» | Создайте новый ключ сообщества и замените его в CRM |
| «У ключа нет нужного доступа» | Создайте ключ с правом «Сообщения сообщества» |
| «Не удалось проверить или сохранить настройки» | Повторите проверку позже; дождитесь сообщения «Подключено» |
| Покупатель не видит предложение | Проверьте подключение CRM и привязку VK к его аккаунту магазина; после привязки или нового входа появится предложение |
| Сообщения покупателю не приходят | Проверьте разрешение сообщений в VK и наличие доступного Telegram; для рассылки — согласие покупателя |
