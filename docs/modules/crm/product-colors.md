# Как объединить два товара по цвету { #combining-two-products-by-color }

Объедините два отдельных товара в одну группу, чтобы покупатель выбирал цвет прямо в карточке.

Где: **Каталог → Товары**.

В примере два товара из категории «Матча», «Демо-матча розовая» и «Демо-матча зелёная», стоят по 295 руб. Отличаются цветом и фото.

<span id="1"></span>

## 1. Подготовьте два товара { #1-prepare-two-products }

В каталоге уже должны быть два простых товара:

| Товар | Фото | Цена |
| --- | --- | --- |
| Демо-матча розовая | Розовый напиток | 295 руб. |
| Демо-матча зелёная | Зелёный напиток | 295 руб. |

Если товаров ещё нет, добавьте каждый через **«Создать → Создать обычный»** — [Категории и товары](products-and-categories.md). Для ресторанного меню, которое передаётся в iiko, используйте **«Добавить из iiko»** и соответствующие позиции меню.

!!! warning "До объединения"
    У выбранных товаров ещё не должно быть заказов. Объединяйте товары одного типа: обычные с обычными, товары из iiko — с товарами из iiko. Запишите остатки по магазинам и артикулы: после объединения их понадобится задать заново. При сохранении новая группа заменит исходные товары.

<span id="2"></span>

## 2. Объедините товары { #2-merge-the-products }

1. Выберите **«Группировать вариативные товары»**.
2. Найдите товары по слову «Демо-матча» и нажмите **Enter**.
3. Отметьте флажками обе строки.
4. Откройте **«Действия → Объединить в варианты»**.
5. В «Редакторе товара» задайте **«Название группы товаров» — «Демо-матча»** и проверьте категорию.

<span id="3"></span>

## 3. Добавьте атрибут «Цвет» { #3-add-the-color-attribute }

На вкладке **«Основное»**, в блоке **«Вариативные атрибуты»**, нажмите **«Создать»**. В окне «Шаблоны вариативных атрибутов» отметьте **«Цвет»** и нажмите **«Выбрать»**.

Если подходящего шаблона нет, создайте его в этом же окне: **«Название» — «Цвет»**, **«Тип» — «Цвет»**, затем **«Сохранить»**. После сохранения выберите шаблон для группы.

<span id="4"></span>

## 4. Назначьте цвета вариантам { #4-assign-colors-to-variants }

В блоке **«Варианты»** отметьте розовый вариант и нажмите **«Изменить»**. В открывшейся карточке прокрутите до блока **«Вариативные атрибуты»** и нажмите **«Изменить»** в строке «Цвет».

Выберите готовый оттенок или **«Создать...»**. Для нового цвета задайте название и оттенок через цветной квадрат:

| Вариант | Название цвета | Пример кода цвета |
| --- | --- | --- |
| Демо-матча розовая | Розовый | `#E7A3AD` |
| Демо-матча зелёная | Зелёный | `#2ECC71` (готовый оттенок) |

Сохраните цвет, проверьте фото и цену варианта, задайте артикул, например **DEMO-PINK**, и нажмите **«Сохранить»** в карточке варианта. Повторите для зелёного варианта с артикулом **DEMO-GREEN**: выберите готовый цвет «Зелёный» из списка. Значения цвета должны различаться.

Чтобы в категории была **одна карточка**, оставьте **«Показывать в каталоге»** только у розового варианта. Зелёный останется доступен через переключатель внутри карточки. Если нужны обе карточки в категории, включите этот флажок у обоих вариантов.

<span id="5"></span>

## 5. Задайте наличие и сохраните { #5-set-stock-and-save }

На вкладке **«Ассортимент»** выберите магазин и задайте количество каждого варианта через **«Изменить»** в его строке. Подтвердите каждую строку кнопкой с галочкой. В примере — по **30 шт.** каждого цвета. Повторите для остальных нужных магазинов — [Наличие](inventory.md).

Нажмите **«Сохранить»** внизу «Редактора товара». Если CRM предложит настроить пустые остатки в других магазинах, выберите «Да» для настройки или «Нет», если в этих магазинах товар пока не продаётся.

## 6. Проверьте результат глазами покупателя { #6-check-the-customer-experience }

Откройте приложение, выберите нужный магазин и найдите «Демо-матча розовая» в категории «Матча». В карточке под ценой появится **«Цвет: Розовый»** и два цветных кружка. Нажатие на зелёный кружок переключит вариант: изменятся фото, название, подпись цвета и артикул. Выбранный кружок выделен обводкой.

???+ example "Пример: выбор цвета в карточке товара"

    Пример с демонстрационными товарами.

Нажатие на зелёный кружок открывает «Демо-матча зелёная» с артикулом DEMO-GREEN, нажатие на розовый возвращает первый вариант.](../../media/app/app-product-colors.gif){ width="960" height="540" loading=lazy }](../../media/app/app-product-colors.gif)

Цена в примере остаётся **295 руб.**; если у вариантов разные цены, она тоже изменится. Кнопки **«Купить»** и **«В корзину»** относятся к выбранному цвету. Перед открытием продаж переключите оба цвета и проверьте фото, цену и наличие. Подробнее — [Витрина и корзина](../app/ui-and-pages.md).
