# Сегменты { #segments }

Выберите клиентов по условиям и проверьте, скольким можно написать. Сообщения с этого экрана не отправляются.

Где: **Аналитика → Сегменты**. На узком экране кнопки над таблицей находятся в «Действия».

<span id="_2"></span>

## Изучить аудиторию { #explore-an-audience }

Выберите сегмент: ниже появятся точка, условия, количество клиентов и их контакты. Состав зависит от текущих данных, а RFM-группы от [сохранённого расчёта](analytics.md#rfm).

Для связи нужны включённые «Рассылки» и контакт в выбранном канале. В таблице остаются и клиенты, которым нельзя написать. Выбор канала меняет оценку доступности, но не условия сегмента. «Обновить предпросмотр» повторяет расчёт; список не фиксируется для будущей кампании.

<span id="_3"></span>

## Создать или изменить { #create-or-edit }

1. Нажмите «Создать сегмент» и укажите название и точку. Единственная точка выбирается автоматически. Профиль клиента проверяется по этой точке за всё время.
2. Выберите нужные условия покупок, RFM-групп, товаров, получения, времени или источника.
3. Проверьте количество клиентов и нажмите «Создать сегмент»; в существующем сегменте — «Сохранить изменения». Подробная таблица появится на основном экране.

Все выбранные условия действуют одновременно; пустое поле не ограничивает отбор. Неизвестное значение не проходит условие: например, отсутствие профиля не означает ноль заказов. Не используйте условие негативной обратной связи: данные для него не собираются, поэтому «Есть» и «Нет» дадут пустую аудиторию.

«Изменить условия» открывает существующий сегмент. «Сохранить изменения» обновит его, «Сохранить как новый» создаст копию. «Отмена» сохранит прежние условия. Если сегмент уже изменили в другой вкладке, сохраните свой ввод как новый или откройте сегмент заново.

## Архив { #archive }

«В архив» убирает сегмент из «Сохранённые». Во вкладке «Архив» выберите «Восстановить и сохранить», проверьте условия и сохраните, чтобы вернуть сегмент. Удалить сегмент нельзя.

Сегменты общие: любой пользователь CRM может менять и архивировать их. [RFM-матрица](analytics.md#rfm) использует свои фильтры. Сохранённый здесь сегмент можно выбрать в [кампании](mass-mailings.md#recipients) вместе с обычными RFM-группами одной точки.
