# Импорт

Массовая загрузка товаров или категорий из файла. Поддерживаются только CSV и «Яндекс Маркет» (YML), Excel и JSON не подойдут.

Где: **Каталог → Импорт**. Шаги мастера:

1. **«Загрузка данных».** «Тип файла» — CSV или «Яндекс Маркет». Для CSV ещё «Тип сущности»: «Товар» или «Категория» (за один раз одна), затем сам файл.
2. **«Настройка импорта»** (только CSV). В колонке «Поле в CRM» поля товара: «Наименование», «Цена продажи», «Себестоимость», «Артикул», «Фотографии» (ссылки), «Описание», «Категория»; у категории «Название» и «Фото». Для каждого поля выберите, откуда взять значение: «Не загружать», «Одно значение для всех», «Из колонки файла» или «Ссылка из колонки». Для товаров можно включить «Объединение товаров»: строки с одинаковым названием в одной категории станут вариантами одного товара, останется указать, чем они отличаются (вес, размер, цвет).
3. **«Проверьте перед сохранением».** Это предпросмотр: записи можно исправить, а пока вы не нажали «Сохранить в каталог», в каталог ничего не записывается. Фотографии по ссылкам загружаются постепенно, сохранить можно после их загрузки.

CSV: разделитель (запятая, точка с запятой, табуляция или «|») определяется сам, первая строка — заголовки. YML пропускает шаг настройки и переносит вложенные категории, артикул, фото, вес и габариты; себестоимость берётся равной цене.

После сохранения:

- Нет цены — будет 0. Нет категории — товар попадёт в «Без категории», а её в приложении нет, поэтому назначьте категории ([Категории и товары](products-and-categories.md)). Категория из CSV, которой нет в CRM, создаётся.
- Все импортированные товары получают количество 0 во всех магазинах. Задайте его в [«Наличие»](inventory.md): иначе покупатель увидит «Нет в наличии».

Сначала проверьте импорт на нескольких строках.
