# Оформление { #appearance }

Настройте главный экран приложения и цвета магазина. Покупатели видят сохранённые изменения без отдельной публикации.

Где: **Каталог → Оформление**.

<span id="_2"></span>

## Главный экран { #home-screen }

1. Откройте «Главный экран» и выберите магазин для предпросмотра, если магазинов несколько.
2. Нажмите «Добавить блок» и выберите подборку товаров, категорий или баннер. Для обычной акции используйте «Верхний баннер с акцией»; [персональную скидку ко дню рождения](promo-codes.md#birthday) в него добавить нельзя.
3. В «Магазины» выберите сети, где нужен блок. После выбора можно добавить товары из их ассортимента. Заполните название и содержимое; у баннера также добавьте изображение.
4. В «Содержимое и порядок» измените порядок стрелками. Верхние баннеры остаются первыми, а каталог с корневыми категориями последним. Стрелки не меняют порядок пунктов внутри верхнего баннера.
5. Проверьте результат в телефоне предпросмотра. Карандаш открывает настройки блока, × удаляет его после подтверждения.

Без названия блок виден в предпросмотре, но скрыт от покупателя. У верхнего баннера с акцией название берётся из акции. При включённом [мультиязычном редакторе](general-settings.md) заполните название для каждого языка.

Для изображений действует ограничение 10 МБ. Для верхнего баннера рекомендуется пропорция 2:3, например 600×900, для баннера в ленте 2:1, например 1200×600. Небольшие GIF загружаются быстрее.

## Цветовая схема { #color-scheme }

1. Откройте «Цветовая схема» и выберите «Светлая» или «Темная».
2. Задайте цвета и проверьте текст, кнопки и сообщения в предпросмотре. Цвет сохраняется сразу после выбора.
3. Для сброса открытой темы нажмите «Вернуть цвета по умолчанию» и подтвердите действие.

В предпросмотре используется товар с фотографией; если такого товара нет, добавьте его в [каталог](products-and-categories.md#products). Наличие в предпросмотре приведено для примера. Покупатель выбирает тему в [профиле приложения](../app/account.md).
