# Начало использования CRM

Эта страница проведёт вас по первому дню работы в CRM Tellem: от входа в систему до момента, когда магазин готов принимать заказы из клиентского приложения.

## 1. Вход в CRM

1. Откройте адрес вашей CRM — его вы получаете от команды Tellem при подключении.
2. Введите «Логин» и «Пароль» и нажмите «Войти».
3. Отметьте «Запомнить», чтобы не вводить данные при каждом входе.

## 2. Мастер первичной настройки

При первом входе CRM открывает окно «Приветственная конфигурация» — опрос из четырёх шагов о вашем бизнесе. Прогресс отображается вверху окна («Шаг 1 из 4»), вперёд ведёт кнопка «Далее», назад — кнопка «Назад».

1. **Тип бизнеса** — выберите один из вариантов: «Офлайн магазин / сеть магазинов», «Онлайн-магазин» или «Ресторанный / кафе».
2. **«Что для вас важнее всего в системе?»** — отметьте важные для вас возможности. Для типа «Онлайн-магазин» дополнительно отмечаются «Каналы продаж».
3. **«Расскажите подробнее о вашем бизнесе»** — ответьте на вопрос о размере бизнеса (для онлайн-магазина — «Сколько у вас сотрудников?», для офлайн-магазина — «Сколько у вас точек?», для ресторана — «Сколько у вас посадочных мест?») и на вопрос «Какие способы оплаты используете?» — «Наличные», «Банковская карта», «Онлайн-оплата».
4. **Завершение** — мастер показывает сообщение «Настройки успешно применены»; нажмите «Завершить».

!!! note
    На каждом шаге нужно выбрать хотя бы один вариант — иначе мастер покажет предупреждение и не пропустит дальше. Пока опрос не завершён кнопкой «Завершить», окно открывается заново при каждом входе в CRM.

## 3. Настройки → Основные

Откройте «Настройки → Основные» и проверьте базовые параметры магазина. Изменения на этом экране сохраняются сразу — отдельной кнопки сохранения нет.

- **«Выбор страны»** — страна осуществления бизнеса. Страну можно изменить, только пока в CRM нет ни одного магазина и ни одного заказа; после этого поле становится доступным только для чтения.
- **«Сортировка товаров»** — порядок товаров в каталоге приложения: «От новых к старым», «В алфавитном порядке», «От дешевых к дорогим» или «От дорогих к дешевым».
- **«Автоматическое создание ассортимента»** — включено: при создании товара он добавляется с нулевым количеством во все магазины и склады; выключено: товар нужно добавлять в ассортимент вручную на экране «Каталог → Наличие».
- **«Товары с нулевым количеством»** — включено: закончившиеся товары остаются видны в каталоге; выключено: товары с нулевым остатком скрываются из каталога.
- **«Бронирование товаров»** — включено: товар резервируется на складе при добавлении в корзину, а поле «Время, спустя которое нужно обнулить товары в корзине» задаёт срок брони (от 5 до 300 минут, по умолчанию 30); выключено: добавление в корзину остатки не резервирует, поле времени недоступно для редактирования.
- **«Резервировать товары вместо покупки»** — режим магазина без оплаты: вместо покупки клиентам предлагается забронировать товар или услугу.
- **«Предупреждение о совершеннолетии»** — включено: при открытии приложения клиент подтверждает совершеннолетие нажатием кнопки; выключено: предупреждение не показывается.
- **«Мультиязычный редактор»** — включено: при редактировании текстов открывается редактор с переводами; выключено: текст редактируется на одном языке.
- **«Предупреждение для клиентов магазина»** — объявления, которые увидят покупатели: например, о повышенном сроке обработки заказов.
- **«Дополнительная информация для профиля пользователя»** — поля, отображаемые в профиле покупателя в приложении.

## 4. Каталог → Магазины

На экране «Магазины» создаются точки продаж. Кнопка «Создать» предлагает два варианта:

- **«Магазин»** — одиночная точка продаж;
- **«Сеть магазинов»** — группа точек с общими настройками.

В редакторе сети магазинов заполните:

1. **«Основная информация»** — название, «Статус» («Открыта», «Временно закрыта» или «Помещена в архив») и описание — график работы магазинов или любая другая полезная информация.
2. **«Магазины в сети»** — добавьте точки кнопкой «Добавить магазин». У каждого магазина указываются название и адрес («Город», «Улица», «Номер дома»); вместе с магазином создаются его склад и пункт выдачи. Сеть должна содержать хотя бы один магазин.
3. **«Управление способами получения»** — включите переключателями способы, доступные покупателям: «Доставка», «Самовывоз», «В заведении», «Онлайн».
4. **«Управление способами оплаты»** — включите способы оплаты для этой сети. Сами способы создаются на экране «Настройки → Оплата» (см. раздел 7).

!!! warning
    Способ получения «Онлайн» не может быть включён одновременно с другими способами, а сеть с активным способом «Онлайн» может содержать только один магазин.

Кнопка «Копировать ссылку» на экране «Магазины» копирует прямую ссылку на выбранный магазин.

## 5. Каталог → Категории и Каталог → Товары

### Категории

На экране «Каталог → Категории» создайте структуру каталога. В «Редакторе категории» поле «Родительская категория» определяет вложенность: выберите категорию верхнего уровня, чтобы создать вложенную структуру вглубь каталога, или оставьте поле пустым, чтобы создать стартовую категорию. У категории задаётся изображение.

### Товары

На экране «Каталог → Товары» кнопка «Создать» предлагает два типа:

- **«Товар»** — обычный товар; у него может существовать только один вариант.
- **«Вариативный товар»** — товар с вариантами, которые различаются значениями «Вариативных атрибутов» (например, цвет или размер). Атрибут имеет «Тип атрибута» — «Цвет» или «Текст».

Редактор товара состоит из вкладок «Основное» и «Варианты». На вкладке «Основное» заполните блок «Общая информация» — название, «Цена продажи», «Артикул», «Себестоимость», описание, «Характеристики» — и загрузите «Изображения». На вкладке «Варианты» задаются значения вариативных атрибутов. У каждого варианта есть переключатель «Показывать в каталоге»: выключите его, чтобы скрыть вариант из приложения, не удаляя товар.

!!! tip
    Для изображений товаров и категорий рекомендуется соотношение сторон 1 к 1, например 600x600 или 1080x1080 пикселей. Поддерживаются и анимированные GIF, но GIF не сжимаются и отдаются как есть — загружайте файлы небольшого размера.

## 6. Каталог → Оформление

Экран «Оформление» отвечает за внешний вид приложения и состоит из двух вкладок:

- **«Главный экран»** — конструктор главного экрана магазина: баннеры, списки и сетки товаров и категорий с живым превью в макете телефона;
- **«Цветовая схема»** — цвета оформления магазина.

Подробная инструкция по конструктору — на странице [Оформление главного экрана](main-page.md).

## 7. Настройки → Оплата

Экран «Оплата» содержит список «Варианты оплаты». Способы «Наличными при получении» и «Картой при получении» созданы в системе по умолчанию — их не нужно добавлять и нельзя удалить. Онлайн-оплату добавляет кнопка «Новый сервис»: «Альфа банк», «СБП (Альфа банк)», «Т-Банк», «СБП (Т-Банк)», «Сбербанк», «СБП (Сбербанк)», «СБП (Аркопэй)», «ЮKassa», «Робокасса», «Бета трансфер» или «Перевод онлайн».

Созданные варианты оплаты включаются и выключаются в конкретной сети магазинов — «Каталог → Магазины», блок «Управление способами оплаты».

Пошаговая настройка каждого способа — на странице [Настройка способов оплаты](new-payment-method.md).

## 8. Опционально: Интеграции → Telegram

Если вы хотите использовать Telegram как дополнительный канал продаж, свяжите CRM с вашим ботом. Для работы клиентского приложения в браузере и как PWA этот шаг не нужен.

1. Откройте «Интеграции → Telegram».
2. Включите переключатель «Интеграция с Telegram».
3. Вставьте токен из @BotFather в поле «Токен бота». Настройки на этом экране сохраняются автоматически при изменении.
4. Настройте «Приветственное сообщение», изображение (кнопка «Загрузить файл», до 10 МБ) и «Функциональные кнопки» — бот отправит их покупателю в ответ на команду `/start`.

Кнопку запуска приложения бот создаёт автоматически — настраивать её у @BotFather не нужно. Как создать бота и получить токен — на странице [Настройка Telegram-бота](../../getting-started/bot-setup.md).

## 9. Работа с заказами

Заказы из приложения появляются на экране «Заказы». Статусы заказов предустановлены системой, настраивать их не нужно:

- новый заказ получает статус «Новый», заказ с онлайн-оплатой — «Ожидает оплаты»;
- обработка: «Новый» → «Ожидает обработки» → «Собирается»;
- получение: «В доставке» (для доставки) или «Ожидает получения» (для самовывоза), затем «Завершён»;
- онлайн-оплата: «Ожидает оплаты» → «Ожидает подтверждения оплаты» → «Оплачено»; при неуспешной оплате — «Ошибка оплаты»;
- конечные статусы: «Завершён», «Отменён», «Возврат».

## 10. Аналитика и экспорт

- Раздел «Аналитика» содержит экраны «RFM», «Когорты», «Заказы», «Клиенты», «Метки» и «Отчеты» — здесь вы следите за продажами и клиентской базой.
- Таблицы заказов, клиентов, товаров и остатков («Наличие») выгружаются в Excel кнопкой экспорта на панели таблицы.

Если возникнут вопросы — в меню CRM есть раздел «Помощь» для связи с командой Tellem.
