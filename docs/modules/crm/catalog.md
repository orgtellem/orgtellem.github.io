# Каталог { #catalog }

Для нового магазина сначала настройте [точки, получение и оплату](stores-and-delivery.md). Затем добавьте товары, задайте наличие и проверьте их в приложении покупателя.

<div class="grid cards" markdown="1">

- :material-store-outline: **Магазины**

    Создать точку или сеть и включить доступные способы получения и оплаты.

    [Настроить магазины](stores-and-delivery.md)

- :material-shape-outline: **Категории и товары**

    Создать товар вручную, добавить варианты и распределить товары по категориям.

    [Добавить товары](products-and-categories.md)

- :material-file-upload-outline: **Импорт**

    Загрузить категории и товары из CSV или YML; меню ресторана добавить из iiko.

    [Импортировать каталог](catalog-import.md) · [Добавить меню iiko](iiko.md#import-products)

- :material-palette-outline: **Варианты по цвету**

    Объединить товары и показать покупателю выбор цвета.

    [Объединить товары](product-colors.md)

- :material-warehouse: **Наличие и продажа**

    Задать остатки по точкам или убрать товар с продажи.

    [Изменить наличие](inventory.md)

- :material-view-dashboard-outline: **Оформление**

    Выбрать блоки главного экрана и цвета приложения.

    [Оформить приложение](main-page.md)

</div>

Если товар не появился у покупателей, проверьте [категорию](products-and-categories.md#categories) и [наличие в сети](inventory.md#check-chain-availability). Весь порядок настройки есть в [чек-листе запуска](getting-started.md).
