# Что-то не работает { #troubleshooting }

Найдите свой случай и откройте нужный раздел инструкции.

## Владельцу и сотруднику магазина { #store-owners }

| Ситуация | Что проверить |
| --- | --- |
| Не получили доступ в CRM или забыли пароль | [Получение доступа и вход](getting-started/registration.md#signing-in-to-the-crm); данные для входа и восстановление пароля уточните в [поддержке Tellem](https://t.me/tellem_tech_bot) |
| Товар не виден в приложении | [Категорию товара](modules/crm/products-and-categories.md#categories), [наличие и продажу в сети](modules/crm/inventory.md#check-chain-availability) |
| Покупатель видит «Заказ недоступен» | [Способы получения в магазине](modules/crm/stores-and-delivery.md), затем [контрольный заказ по чек-листу](modules/crm/getting-started.md#test-order) |
| Деньги поступили, но статус заказа не обновился | [Онлайн-оплату и принятие заказа](modules/crm/orders.md#online-payment), [настройку уведомлений провайдера](modules/crm/payment-providers.md#provider-notifications) |
| Сотрудник не получает сообщения о заказах | [Получателей, магазины и каналы уведомлений](modules/crm/crm-notifications.md#seller-recipients) |
| Не создалось отправление СДЭК или Яндекс | [Статус и сообщение в «Информация о доставке»](modules/crm/delivery.md#delivery-information) |
| Ошибка iiko или заказ не появился на кассе | [Проверку заказа и ошибки iiko](modules/crm/iiko-errors.md) |
| Рассылка не отправлена или отправлена частично | [Статус рассылки и действия после отправки](modules/crm/mass-mailings.md#results) |

## Покупателю { #customers }

| Ситуация | Что проверить |
| --- | --- |
| Не получается войти | [Способы входа и получение нового кода](modules/app/account.md#sign-in-and-registration) |
| Нельзя оформить заказ или выбрать получение | [Способ получения и сообщение о недоступности](modules/app/checkout.md#delivery-method) |
| Промокод не подходит | [Сообщение под полем промокода](modules/app/checkout.md#promo-code) |
| Платёж не завершён или срок оплаты истёк | [Подтверждение и оплату заказа](modules/app/checkout.md#confirmation-and-payment) |
| Нет пункта установки приложения | [Установку на вашем устройстве](modules/app/account.md#installation) |
| Не приходят сообщения в VK | [Разрешение сообщений и ошибки подключения](modules/app/customer-notifications.md#if-it-does-not-work) |
| Не включаются уведомления на устройстве | [Push и ограничения для iPhone и iPad](modules/app/customer-notifications.md#push) |

По вопросам оплаты, отмены и возврата обращайтесь в магазин через **Профиль → Поддержка**, если магазин указал контакты. Сообщите номер заказа и опишите, на каком шаге возникла проблема. Перед отправкой снимка скройте пароли, коды подтверждения и лишние персональные данные.
