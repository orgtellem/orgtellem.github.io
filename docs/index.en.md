# About Tellem { #about-tellem }

Tellem has two parts: a customer app for placing orders, and a CRM where store owners manage their catalog, orders, and customers.

Customers can open the app from a browser link, install it on a phone, or open it inside Telegram if the store connected a bot. Telegram is optional.

Screenshots may show the Russian interface; the steps describe the same actions.
