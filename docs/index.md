# О продукте { #about-tellem }

Tellem состоит из двух частей: клиентского приложения, где покупатели оформляют заказы, и CRM, где владелец ведёт каталог, заказы и клиентов.

Покупатель может открыть приложение по ссылке в браузере, установить его на телефон или открыть внутри Telegram, если магазин подключил бота. Telegram необязателен.

## Помощь в CRM { #help-in-the-crm }

- Пункт меню «Помощь» открывает этот сайт.
- Иконка «?» в шапке открывает подсказки по текущему разделу и контакты поддержки.

Поддержка: [Telegram](https://t.me/tellem_tech_bot), [ВКонтакте](https://vk.link/tellem_it), сайт [tellem.tech](https://tellem.tech).
